# Barbarians — Build Manager

![Barbarians](https://i.postimg.cc/G3fS4X6v/barbarelogo.png)

A desktop tool to **export and import player builds** between Conan Exiles servers.

## Features
- Export a clan or player build to a portable JSON file
- Import a build into any server database (Solo, Dedicated, G-Portal)
- Automatic database backup before every import
- Detects required mods with Steam Workshop links
- Collision check — blocks import if the map location is already occupied
